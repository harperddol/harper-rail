OFFICIAL

코레일 로그인은 공식 웹사이트에서 직접 진행합니다. Harper Rail은 회원번호, 비밀번호, 결제정보를 입력받거나 저장하지 않습니다.

취소표 감시 · 개인 서버 (베타)

코레일과 별도로 배포한 개인 서버를 연결합니다. GitHub Pages만으로는 자동 감시가 실행되지 않습니다. 서버 비밀번호는 이 브라우저 탭에서만 사용합니다.

위 열차 설정의 탑승일, 역, 시간, 열차번호, 좌석등급을 사용합니다. **열차번호는 필수**, 인원은 1명만 지원합니다.
